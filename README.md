# Demo

電腦網頁以手機畫面呈現，左側切換情境。

## 快速使用

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env        #填入 OPENAI_API_KEY 
.venv/bin/python app.py
```

開啟 http://localhost:5050

註： 不填 API key 也能完整操作（用模擬的）。

## 體驗流程

依序點左側情境：

| # | 情境 | 試試看 |
|---|---|---|
| 1 | 行程推薦 | 看 AI 依行程推薦的 eSIM，按「一鍵加入購物車」 |
| 2 | AI 選方案 | 按「✦ AI 幫我選」回答 3 題，看推薦方案與理由 |
| 3 | 客服 | 問「怎麼安裝？」；問無關問題會轉真人 |
| 4 | 問經驗 | 問「平日早上人多嗎？」；問到第 4 次會提示購買 eSIM |
| 5 | 現場問答 | 嵐山現場，回答優先引用最新回報 |
| 6 | 經驗換流量 | 點推播 → 錄音或點「正常」範例 → 送出，通過審核送 500MB；點「亂講」會被擋 |
| 7 | 經驗卡 | 看流量加碼與旅後經驗卡 |


行程、方案、經驗庫等業者資料以 `data/` 下的 JSON 模擬。
